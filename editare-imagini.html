Pregatire imagini pentru galerie

Alege pozele din telefon sau calculator. Aici se micsoreaza si se transforma in format usor pentru site. Nimic nu se trimite nicaieri, totul ramane in browserul tau.

  1. Alege pozele.
  2. Scrie la fiecare o descriere scurta (ce se vede in poza).
  3. Descarca fiecare imagine cu 'Descarca' si incarc-o in dosarul img/galerie din GitHub ('Add file' > 'Upload files').
  4. Copiaza liniile de mai jos in fisierul galerie.json ('Edit' pe fisier), intre parantezele drepte, apoi 'Commit changes'.
